# sarihamoud.com

Static personal/professional website for Dr. Sari Hamoud.

## Publish with GitHub Pages

1. Create a GitHub repository named `sarihamoud.com` (or use another repository name).
2. Upload `index.html` and `style.css`.
3. In GitHub: Settings → Pages → deploy from the `main` branch.
4. Add `sarihamoud.com` as the custom domain.
5. Configure Dynadot DNS using the records GitHub provides for the current Pages setup.
6. Enable HTTPS once GitHub has verified the domain.

Do not delete existing Dynadot MX records if you use email on the domain.
